## What I'm Building

| Project | Focus | Overview |
|---|---|---|
| [AskIT AI](https://github.com/saadkhan-git/AskIT-AI) | Local AI assistant | A Streamlit-based assistant powered by locally run LLMs, with model configuration, system prompts, SQLite integration, and user authentication. |
